// Topic 01

Algebra

8 exercises
01
Solve: 3x + 7 = 22
Linear Equations · Easy
Easy
Solution:
3x + 7 = 22
3x = 22 - 7
3x = 15
x = 15 ÷ 3
x = 5
02
If x² - 5x + 6 = 0, find the values of x.
Quadratic Equations · Medium
Medium
Solution:
x² - 5x + 6 = 0
Factor: (x - 2)(x - 3) = 0
x - 2 = 0 or x - 3 = 0
x = 2 or x = 3
03
Expand: (x + 3)(x² - x + 2)
Polynomials · Medium
Medium
Solution:
(x + 3)(x² - x + 2)
= x(x² - x + 2) + 3(x² - x + 2)
= x³ - x² + 2x + 3x² - 3x + 6
= x³ + 2x² - x + 6
04
Find the roots of x² + 6x + 9 = 0 using completing the square.
Quadratic Equations · Hard
Hard
Solution:
x² + 6x + 9 = 0
(x + 3)² = 0
x + 3 = 0
x = -3 (repeated root)

Easy

Find dY/dX if Y = (3x² + 2)⁴
Chain Rule · Medium
Medium
Solution:

= 24x(3x² + 2)³
04
Evaluate: ∫x·eˣ dx
Integration by Parts · Hard
Hard
Solution:
Using integration by parts:
∫u dv = uv - ∫v du
Let u = x, dv = eˣdx
= xeˣ - ∫eˣdx
= xeˣ - eˣ + C
// Topic 03

Geometry

5 exercises
01
Find the area of a triangle with base 8cm and height 5cm.
Area · Easy
Easy
Solution:
Area = ½ × base × height
= ½ × 8 × 5 = 20 cm²
02
A circle has radius 7cm. Find its circumference.
Circles · Easy
Easy
Solution:
Circumference = 2πr = 2 × π × 7
= 14π cm ≈ 43.98 cm
03
Find the distance between points (2, 3) and (5, 7).
Coordinate Geometry · Medium
Medium
Solution:
Distance = √[(x₂-x₁)² + (y₂-y₁)²]
= √[(5-2)² + (7-3)²]
= √[3² + 4²] = √25 = 5 units
